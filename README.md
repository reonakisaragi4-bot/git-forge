A standalone GitHub-compatible git forge in pure Node.js (standard library only, no git binary): git smart HTTP (upload-pack v2 / v0, receive-pack v0 with pack parsing and generation in pure JS), REST v3 (repositories, contents, labels, issues, pull requests, merge), GraphQL v4, and MCP over JSON-RPC 2.0 — all on one in-memory store, deterministic across replays.

## Run it

```sh
node --experimental-strip-types main.ts
```
